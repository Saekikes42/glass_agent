# Glass Agent в Telegram

В личном чате можно поручить работу агенту, согласовать материал и посмотреть отчёт. Готовый пост отправляется в канал, указанный в карточке согласования.

## Пользователю

1. Откройте бота по ссылке администратора и отправьте `/start`. Если компания недоступна, передайте администратору числовой Telegram ID из ответа.
2. Отправьте `/companies`, затем `/use salavatsteklo`, подставив нужный код компании. Роль `viewer` даёт доступ к просмотру, `editor` — к поручениям и черновикам, `approver` или `owner` — к согласованию.
3. Напишите поручение обычным сообщением. Назовите тему, площадку, желаемый визуал и время.

   > Подготовь пост для Telegram об Ultraview R по материалам компании. Добавь PNG из фирменного шаблона, предложи завтра в 10:00 по Екатеринбургу и отправь материал на согласование. Укажи источник фактов.

   Чтобы сделать пост по конкретному сообщению, ответьте на него или перешлите его и напишите задачу отдельным сообщением. Бот использует текст или подпись. Для видео или фотографии без подписи пришлите описание. Можно также попросить агента найти материал в уже подключённой базе знаний компании и указать источник.

4. Откройте карточку нового черновика или отправьте `/posts`, чтобы увидеть сохранённые черновики и материалы на согласовании. Кнопка «На согласование» передаёт конкретный черновик на проверку. Перед решением проверьте текст, изображение, площадку, канал и время.

   | Кнопка | Результат |
   | --- | --- |
   | **Согласовать** | Сохраняет одобрение. При предложенном времени сразу ставит пост в расписание |
   | **Согласовать и опубликовать** | Ставит пост в очередь ближайшего запуска планировщика |
   | **На доработку** | Бот ждёт комментарий отдельным сообщением. Проверьте новую редакцию и согласуйте её заново |
   | **Отклонить** | Закрывает заявку без публикации |

5. После отправки проверьте уведомление и сообщение в канале. При повторном нажатии бот показывает текущий статус. Если канал назначения не задан, бот не поставит пост в очередь. После изменения текста, картинки или канала откройте актуальную карточку и согласуйте её заново.

Для отчёта отправьте `/report` за 7 дней или `/report 30` за 30 дней. `/tasks` показывает регулярные задачи, `/ai` — состояние ChatGPT, `/help` — команды. В `/inbox` редактор может подготовить черновик ответа на собранный комментарий, согласующий — проверить и отправить его.

## Администратору

1. Подготовьте PostgreSQL и подключите ChatGPT по общей инструкции. Запишите в локальный `.env` токен от BotFather в `TG_BOT_TOKEN` и Telegram ID администраторов в `ADMIN_TELEGRAM_IDS`. [Установка](ADMIN_GUIDE.md)
2. Из корня проекта с активированной виртуальной средой выполните две команды в отдельных терминалах. На один токен используйте один процесс бота.

   ```powershell
   python -m scripts.bot
   python -m scripts.scheduler
   ```

3. В личном чате настройте компанию. Для существующей компании начните с `/use <slug>`. Замените ID участника и имя канала своими.

   ```text
   /newcompany Салаватстекло
   /companies
   /invite 123456789 editor
   /addsource website https://salstek.ru/
   /addsource telegram_web https://t.me/salstek
   /sync
   /setchannel telegram @test_channel
   ```

4. Добавьте бота администратором тестового канала с правом публиковать. Проверьте настройку командой `python -m scripts.doctor --live`. Для сбора новых публикаций собственного канала администратор платформы может дополнительно задать `/addsource telegram_bot -1001234567890`. Для комментариев подключите бота к группе обсуждения и укажите `/setchannel telegram_discussion -1001234567890`, подставив ID этой группы.

5. Загрузите документы через `POST /api/companies/{id}/files`, фон или логотип — в медиатеку через `POST /api/companies/{id}/media`. Бот может собрать PNG из шаблона Pillow и прикрепить его к существующему посту. Для разового импорта закрытой истории используйте разрешённый экспорт JSON. Такой источник хранит снимок истории. Загружайте контент, разрешённый для использования по правилам площадки. [Источники и медиатека](ADMIN_GUIDE.md#5-загрузить-источники)

В живом тесте бот принял поручение, показал PNG, обработал комментарий к доработке, принял согласование кнопкой и прислал уведомление после публикации в закрытом тестовом канале. В отдельной проверке агент нашёл расписание волейбольных матчей в импортированной истории, подготовил анонс и собрал PNG в Telegram. Пост с изображением был отправлен в тестовый канал.
