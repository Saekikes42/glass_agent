## Ограничения ChatGPT Plus (Sign in with ChatGPT, Preview)

* Документировано для open-source/локальных приложений и собственных VM; платный/облачный сервис для чужих
  компаний — только после одобрения заявки OpenAI ([CHATGPT_PLUS_OAUTH.md](CHATGPT_PLUS_OAUTH.md)).
* Общее 5-часовое окно лимита Plus для всех приложений пользователя; при исчерпании — пауза запросов и сообщение.
* Нет генерации изображений, file search, code interpreter, аудио/видео — поэтому изображения из шаблонов,
  эмбеддинги локальные.
* Без подключения AI-функции возвращают `AI_CONNECTION_UNAVAILABLE`; парсеры, поиск, согласование, публикация,
  отчёты по данным работают.
