# Glass Agent во ВКонтакте

Работайте в личных сообщениях сообщества с ботом. Площадку публикации и целевую стену проверяйте по карточке согласования. Из личного диалога VK можно готовить материал и для Telegram.

## Пользователю

1. Откройте «Написать сообщение» в сообществе и отправьте `/start` от своего личного аккаунта VK. Бот отвечает автоматически, когда запущен. В разделе «Сообщения сообщества» администратор видит переписку со стороны сообщества. Для обращения к боту откройте личный диалог. Если аккаунт ещё не привязан, передайте администратору VK ID из ответа бота и свой Telegram ID.
2. После привязки отправьте `/companies` и `/use salavatsteklo`, подставив нужный код. Права берутся из членства в этой компании. `editor` может ставить задачи и передавать черновики, `approver` или `owner` — согласовывать. `viewer` может смотреть материалы и отчёты.
3. Отправьте поручение текстом. Для поста укажите площадку, тему, пожелания к изображению и срок.

   > Подготовь пост для стены VK о стекле Ultraview R по материалам компании. Добавь квадратный PNG из фирменного шаблона. Предложи время завтра в 10:00 по Екатеринбургу и отправь на согласование.

4. Откройте уведомление или отправьте `/posts`. Если материал остался в черновиках, нажмите «На согласование». Под карточкой проверьте текст, PNG, сообщество и время.

   | Кнопка | Результат |
   | --- | --- |
   | **Согласовать** | Сохраняет одобрение и ставит в расписание, если предложено время |
   | **Согласовать и опубликовать** | Ставит пост в очередь ближайшего запуска планировщика |
   | **На доработку** | После нажатия отправьте замечание обычным сообщением. Следующую редакцию проверьте и согласуйте заново |
   | **Отклонить** | Закрывает заявку без отправки |

5. Посмотрите `/report` за 7 дней или `/report 30` за 30 дней. `/tasks` показывает регулярные задачи. Отчёт использует только собранные показатели.

Комментарии к публикациям VK собирает фоновая задача `collect_comments`. С ними работают через `/inbox` в Telegram или через административный API. В личных сообщениях VK используйте команды `/help`, `/companies`, `/use`, `/posts`, `/report` и `/tasks`.

## Администратору

1. В тестовом сообществе включите личные сообщения и Bots Long Poll. Выберите версию API 5.199 и события `message_new`, `message_event`. В локальном `.env` задайте `VK_BOT_TOKEN` с правами на сообщения и положительный `VK_BOT_GROUP_ID`. [Настройка и окружение](ADMIN_GUIDE.md#4-подключить-личные-сообщения-vk)
2. Запустите VK-бота из корня проекта в активированной виртуальной среде. Telegram, VK и планировщик должны использовать одну БД. На одно сообщество запускайте один процесс опроса.

   ```powershell
   python -m scripts.vk_bot
   ```

3. Дайте участнику роль компании через Telegram `/invite <telegram_id> <роль>`. Когда он напишет `/start` в VK, проверьте принадлежность аккаунтов и выполните команду с их ID.

   ```powershell
   python -m scripts.manage link-identity vk 123456789 --telegram-id 987654321
   ```

4. Для чтения стены заполните `VK_ACCESS_TOKEN` ключом с доступом к `groups.getById` и `wall.get`. Для уже подключённого источника выполните `python -m scripts.manage sync salavatsteklo --type vk`. Публикация требует пользовательский ключ с правами на целевую стену и с правом `photos` для постов с изображениями. Ключ для личных сообщений даёт доступ к диалогу.
5. В Telegram из нужной компании выполните `/setchannel vk club123456789` со своим ID, затем задайте ключ публикации компании и проверьте права без отправки.

   ```powershell
   python -m scripts.manage secret salavatsteklo vk_token
   python -m scripts.doctor --live --vk-publish-company salavatsteklo
   ```

6. Оставьте `python -m scripts.scheduler` запущенным для согласованных публикаций, отчётов и сбора комментариев. Для проверки отправки создайте отдельный тестовый пост и согласуйте его на тестовую стену.

На реальных данных проверены чтение стены Салаватстекло, личный диалог с ChatGPT и отклонение материала кнопкой. При живой попытке отправки VK вернул ошибку 15 на `wall.post` из-за ограничения типа приложения. Для повторной проверки нужен ключ приложения, которому VK разрешает `wall.post` на выбранной стене.
